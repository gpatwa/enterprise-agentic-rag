## `analytics.analyze`

**Ask a governed analytics question.** Start or replay a governed run for a natural-language question. The same idempotency key and question return the same run; reusing a key with a different question is refused. The outcome is an answer, a clarification question, a review pause, a refusal, or a failure.

| Argument | Type | Required | Constraints |
|---|---|:---:|---|
| `purpose` | string | yes | minLength=1, maxLength=255 |
| `request_text` | string | yes | minLength=3, maxLength=2000 |
| `idempotency_key` | string | yes | pattern=^[A-Za-z0-9._:-]{8,128}$ |

Unknown arguments are rejected.

## Errors

`unknown_tool` (404), `invalid_tool_call` / `invalid_arguments` (422), `human_required` (403), plus the service codes of the REST API (`purpose_not_authorized`, `run_not_found`, `idempotency_key_reused`, `review_not_permitted`, ...). `analytics.evidence` adds `run_not_terminal` and `evidence_unavailable` (409) and `evidence_not_configured` (503).
